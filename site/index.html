How it works

From pixels to meaning.

01

See at several scales

A ResNet-50 backbone and feature pyramid turn the image into maps that carry information about small and large objects.

02

Look for objects

The region proposal network suggests boxes worth examining. RoI pooling extracts a compact feature for each proposal.

03

Make the call

The trained prediction head assigns a VOC class, refines the box, and gives each detection a confidence score.

Training the detector

20 classes. One trained head.

We started with TorchVision's COCO-pretrained Faster R-CNN, using a ResNet-50 backbone and feature pyramid. We froze the detector and fine-tuned its final class and box predictor on PASCAL VOC 2007.

Training
2,501 images · 10 epochs · SGD
Validation
2,510 images · epoch 10 selected
Test
4,952 images · 81.8% VOC 2007 mAP
Browser edition
ONNX · 640 × 640 letterboxed input

The reported test mAP comes from the original PyTorch evaluation. Browser preprocessing uses a fixed input size and can produce different results. The pipeline animation illustrates inference. The model's trained weights stay fixed while you test it.
